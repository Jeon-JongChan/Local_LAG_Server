================================================================================
local-rag — 프로젝트 개요
================================================================================
작성 기준: 현재 코드베이스 (OpenDataLoader + FAISS/SQLite + bge-m3/reranker + llama.cpp)

--------------------------------------------------------------------------------
1. 목적
--------------------------------------------------------------------------------
로컬 PDF 문서를 색인하고, 사용자 질문에 대해 검색 기반(RAG) 답변을 생성한다.
모든 추론·임베딩·파싱은 로컬에서 동작하며, 외부 클라우드 API는 사용하지 않는다.

--------------------------------------------------------------------------------
2. 전체 파이프라인
--------------------------------------------------------------------------------

[전체 흐름]

  ┌─────────────┐     색인      ┌──────────────────────┐
  │  data/docs  │ ───────────► │  FAISS + SQLite      │
  │  (PDF)      │              │  (벡터·청크·채팅)    │
  └─────────────┘              └──────────┬───────────┘
                                          │ 검색
                                          ▼
  ┌─────────────┐     질문      ┌──────────────────────┐     답변
  │   사용자    │ ───────────► │  RAG (검색→리랭크→LLM) │ ───────► 출처 포함
  └─────────────┘              └──────────────────────┘


[인제스트]  PDF → 색인 저장

  ┌──────────┐   ┌─────────────────┐   ┌──────────────┐   ┌──────────┐   ┌─────────────────────┐
  │ PDF 수집 │──►│ OpenDataLoader  │──►│ 청크 분할    │──►│ bge-m3   │──►│ FAISS (벡터)        │
  │ *.pdf    │   │ JSON+page/bbox  │   │ 200~800자    │   │ 임베딩   │   │ SQLite (본문·메타)  │
  └──────────┘   └─────────────────┘   └──────────────┘   └──────────┘   └─────────────────────┘


[질의]  질문 → 답변

  ┌────────┐   ┌──────────┐   ┌────────────┐   ┌──────────────────┐   ┌─────────────┐   ┌──────────────┐
  │ 사용자 │──►│ bge-m3   │──►│ FAISS      │──►│ bge-reranker     │──►│ llama-server│──►│ 답변 + 출처  │
  │ 질문   │   │ 질의임베딩│   │ Top-20     │   │ v2-m3 Top-4     │   │ Qwen        │   │ 파일·페이지  │
  └────────┘   └──────────┘   └────────────┘   └──────────────────┘   └─────────────┘   │ ·bbox        │
                                                                                        └──────────────┘
  웹: 세션 히스토리 + think_mode(instant/think/auto) 지원

4. 실행 방법 (요약)
--------------------------------------------------------------------------------
사전 요구:
  - Python 3.10+
  - Java 11+ (OpenDataLoader PDF)
  - llama-server (llama.cpp, Qwen GGUF 로드)

  pip install -r requirements.txt
  llama-server -m <qwen.gguf> --port 8080 -c 4096

명령:
  python app/main.py ingest --reset    # PDF 전체 재색인
  python app/main.py ask --question "..."
  python app/main.py serve             # http://localhost:8787

Windows: scripts\local-rag.bat [serve|ingest|ask|llama|models]

  LLAMA_NUM_PREDICT_THINK   16384
  REQUEST_TIMEOUT           600
  WEB_PORT                  8787

--------------------------------------------------------------------------------
6. 지원 범위·제한
--------------------------------------------------------------------------------
  - 입력: PDF만 (data/docs 이하 재귀 탐색)
  - HWP/HWPX/DOCX 등: 미지원
  - 벡터 저장: FAISS + SQLite (Qdrant 미사용)
  - 웹: Vue 세션형 채팅 (think 모드·히스토리)
  - 인제스트: bat/기본 ingest는 --reset 전체 재구축
  - 증분: 코드에 append/skip 로직 있으나, bat는 항상 --reset

--------------------------------------------------------------------------------
7. 모듈 역할 한 줄 요약
--------------------------------------------------------------------------------
  pdf_parser   PDF → OpenDataLoader JSON → 텍스트 요소 목록
  chunker      요소 병합·분할, citation 문자열 생성
  store        FAISS IndexFlatIP + SQLite chunks 테이블
  models       SentenceTransformer(Qwen3-Embedding), Qwen3-Reranker
  llm          POST /v1/chat/completions → llama-server (+ think)
  ingest       인제스트 플랜(full/append/skip) + 파이프라인 실행
  query        dense+BM25 RRF → 리랭크 → LLM → 답변 조립
  chat_db      세션·메시지 영속화
  web_server   세션 API + Vue UI

상세 로직·스키마·API는 overview_detail.txt 참고.
